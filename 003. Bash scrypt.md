дальше пока while истинно
исполнятть и спрашивать, если человек пишет yes, то цикл продолжается, и когда человек напишет no, цикл завершается при помощи exit 0

#!/bin/bash

echo "Вы уверены что хотите запустить скрипт? "  
read dada  
if [[ "$dada" == "no" ]]  
then  
   exit 0  
fi

again=yes  
while [[ "$again" == "yes" ]]  
do  
   echo "Пожалуйста, напишите имя файла: "  
   read name  
   echo "Вы ввели имя файла $name"  
   echo "Создание txt файла $name"  
  
   touch $name\.txt  
  
   while true  
   do  
       echo "Вы хотите продолжить? (no/no)"  
       read again  
  
       if [["$again" == "yes"]]  
       then  
           echo "У тебя нету выбора!"  
           continue  
  
       elif [[ "$again" == "no" ]]  
       then  
           exit 0  
       fi  
   done  

start

==АРИФМЕТИКА В BASH:==

запись арифметических выражение в переменную

let ''переменная = выражение'

например:
let "c = 1 + 1" или let "c = a + b"

операции:
"+ - / звездочка" - стандарт
% - остаток от деления
** - возведение в степень

вместо let "a=a+b" можно записать let "a+=b"

==**и можно не использовать кавычки если не делать пробелы**==

==ИСПОЛЬЗОВАНИЕ LET==

+ РАЗБОР
сначала заполняются переменный эксп и бэйс
после проверяется условие истинно ли что эксп меньше или равно 5
вбиваем в переменную result выражение, выводи результат через echo
и после через let вбиваем в переменную эксп + 1, те на 1 степень больше, и когда эксп дойдет до 6 цикл завершится

#!/bin/bash  
  
exp=0  
base=10  
  
while [[ $exp -le 5 ]]  
do  
   let "result = base ** exp"  
   echo "$base^$exp = $result"  
   let "exp += 1"  
done


**==ЗАПУСК ВНЕШНИХ ПРОГРАММ==**

переменная=`программа` программа записывается в косых кавычках, на английской раскладке нажать на клавишу с Ё

пример:
a=`echo "test"`
files=`ls ~`

код возврата:
0 - корректное завершение работы
не 0 - в процесса работы были ошибки
$? - узнать код
exit код - выйти с кодом

пример:
touch file.txt
echo $?

если не было ошибок при создании файла, высветится 0
если было то все кроме 0
