OSI эталонная модель по 7 уровням
L1 Физический - передает биты по середе
L2 Канальный - добавление MAC адреса
L3 Сетевой - маршрутизация, определение пути по которому пакеты пройдут от А до Б используя IP
L4 Транспортный - разбивка данных на фрагменты и нумерует их, устраняет потери и контролирует их, TCP и UDP
L5 Сеансовый - управление сеансами связи, синхронизация обмена данными
L6 Уровень представления - преобразование данных в понятный приложению формат (ASCII, Unicode), шифрует и сжимает
L7 Прикладной -  интерфейт между сетью и приложениями (HTTP, FTP, SMTP, DNS)

TCP/IP 4 уровня, склеенные уровни OSI:
L1 Канальный - объединение физического и канального уровней, передача данных по LAN (работа Ethernet, WI-FI, PPP и определение MAC адресов)
L2 Межсетевой - маршрутизация, назначение IP + ICMP, ARP (сопоставление IP и MAC адресов)
L3 Транспортный - TCP и UDP, разбивка на фрагменты 
L4 Прикладной - HTTP(S), FTP, SMTP, DNS, SSH

TLS - шифрование данных по сети, согласование алгоритмов, проверка сертификата через цепочку УЦ, генерация общего ключа сеанса и трафик зашифрован (не видно содержимого, что вы делаете на сайте и тд)

SNI - расширение протокола тлс, вначале соединения клиент ( в сообщении ClientHello ) передает серверу имя сайта, нужно чтобы на одном IP работало несколько HTTPS сайтов с разными сертификатами

MAC адрес - локальная сеть, можно искать между компьютерами одной сети
протокол BGP - две системы сообщают друг другу какие ip адреса у нее есть и через кого она добирается до остальные

ip - уникальное число устройства в сети, но оно не принадлежит железу IPv4 (4 числа через точку "192.168.1.1 - от 0 до 255), IPv6 (восемь групп символов через двоеточие "2001:db8::1)

NAT - технология преобразования сетевых адресов, выход множество устройств по локальной сети выходит в общий интернет по общему публичному IP адресу

мпк - магистральный подводный кабель

proxy - посредник между устройством и и интернетом, меняет видимый ip адрес, бывают http(s) прокси для веб сёрфинга, socks прокси для мессенджеров, прямой прокси между мной и интернетом и тд, пример: я заказываю пиццу либо звоня в компанию без прокси, либо через прокси (друга) звоню ему и он заказывает пиццу

vpn - зашифрованный туннель между устройством и сервером, впн действует на все к чему ты подключаешься, прокси конкретно на то что ты его поставил

API -  набор правил и способов, по которым разные программы могут общаться друг с другом, грубо говоря я это приложение, официант это сам API а кухня это сервер или другая программа с нужными данными(функциями), я не захожу на кухню и не готовлю сам а зазказываю через официанта "JSON" самый популярный формат передачи данных в API

endpoint - конкретный url куда отправляется запрос /users

firewall - брандмауэр, контролирует трафик и не пускает опасные соединения, а разрешает только то что безопасно, типо кто то пытается пройти без пропуска и firewall его не пускает, также он может вести дневник кто, когда и куда заходил или стучался

парсинг - извлечение данных со страниц сайтов, парсер это скрипт который это делает

url - адрес ресурса в интернете {https://www.example.com:443/blog/post-1?id=123#section2}, https:// соединение http(s) или ftp, {www.example.com} домен, превращается в ip через dns, 443 это порт

html - язык разметки для создания веб

blockchain - распределенная база данных где информация хранится в виде цепочки блоков, каждый блок содержит данные, хеш предыдущего блока и цифровую подпись

LAN - локальная сеть, группа устройст соединенных друг с другом на небольшой территории, доступ идет через роутер (шлюз)
ethernet тоже что и LAN

WIFI - беспроводная технология для локальных сетей

troubbleshutting - поиск и устранение неисправностей

ping - задержка

SSH - шифрованный туннель между компом и удаленным сервером (базовый порт - 22)

коммутатор - соединение по одной сети и пересылка данных по MAC - адресу

маршрутизатор (роутер) - соединение разных сетей и решает кому, что отправить ориентируясь на IP-адрес

Протокол SMB - сетевой протокол, позволяющий компьютерам в сети обмениваться файлами, подключаться к сетевым принтерам и другим ресурсам

ASCII - американский стандартный код для обмена информацией, стандарт кодирования символов, связывающий буквы, цифры, знаки препинания, каждому символу соответствует определенное число
