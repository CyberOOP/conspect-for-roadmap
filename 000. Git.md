## Что не должно попадать в Git

Лишнее в репозитории делится на несколько понятных групп.
Первое и самое важное – это секреты. Пароли от баз данных, токены доступа, приватные ключи, файлы вроде `.env` с настройками подключения

Вторая группа – то, что генерируется из кода и восстанавливается командой. Папка зависимостей `node_modules`, каталоги сборки `build` и `dist`, кэши вроде `__pycache__`

Третья группа – мусор и временные файлы. Логи (`app.log`, `*.log`), временные файлы, дампы. Они меняются каждую секунду работы программы, и их история не несет никакого смысла.

И последнее – личные и системные файлы, к проекту отношения не имеющие. `.DS_Store` создает Finder на macOS, `Thumbs.db` – проводник Windows, а папки `.idea` и `.vscode`

	git rm --cached .env # убрать из отслеживания, сам файл на диске оставить
Настоящие секреты держат в файле `.env`, который занесен в `.gitignore` и у каждого разработчика свой.
А рядом коммитят его шаблон, обычно `.env.example`, тот же список настроек, но с пустыми значениями:

.env — в .gitignore, с настоящими значениями, в Git не идет 
.env.example — коммитится, это шаблон без секретов
